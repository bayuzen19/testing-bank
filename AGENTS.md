# Hermes bank evaluation
This repository is a synthetic banking PoC used to evaluate a LOCAL coding assistant.
Use local tools only for model inference. No cloud fallback, credential access, git push, or external posting from agent sessions.
Only change files explicitly assigned by the task. Read TASK.md and relevant tests first.
Do not edit tests to obtain a pass. Run the exact acceptance command and report actual output.
Use Node.js 22 ES modules, React and PostgreSQL. Amounts are integer Indonesian rupiah; never use floating-point ledger calculations.
PII is synthetic. Never log passwords, tokens, email addresses, raw names or full account numbers. No remote fonts, trackers or image services.
Report blockers and limitations honestly. This is not production banking software or a compliance certification.
